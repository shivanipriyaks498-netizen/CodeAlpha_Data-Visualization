# Superstore Sales Analysis and Data Visualization

## Project Overview
This project analyzes the Sample Superstore sales dataset using Python. It explores sales, profit, product categories, regional performance, and discount patterns through data analysis and visualizations.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset
- Total Records: 9,994
- Total Columns: 13
- Dataset: Sample Superstore

## Key Results
- Total Sales: $2,297,200.86
- Total Profit: $286,397.02
- Total Quantity Sold: 37,873
- Highest Sales Category: Technology
- Highest Profit Region: West
- Average Discount: 16%

## Visualizations
1. Sales by Category
2. Profit by Region
3. Sales by Sub-Category
4. Profit vs Discount

## Project Files
- `sales_analysis.py` – Dataset analysis
- `sales_visualization.py` – Generates charts
- `sales_report.py` – Generates the business report
- `SampleSuperstore.csv` – Dataset
- `requirements.txt` – Required Python libraries

## How to Run

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the analysis:

```bash
python sales_analysis.py
```

Generate visualizations:

```bash
python sales_visualization.py
```

Generate the report:

```bash
python sales_report.py
```

## Conclusion
This project demonstrates how Python data analysis and visualization can help identify sales trends, regional performance, and business opportunities.
